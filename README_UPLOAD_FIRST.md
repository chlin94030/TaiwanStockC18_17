## 本版修正

1. 完成交易日行情可能已寫入模型，但上市／上櫃官方原始來源尚未同步核實。以前這種狀況會隱藏完整日線的買點分數；現在只要歷史欄位確實計算過，便顯示為「歷史買點分數（非即時）」，同時維持買賣訊號封鎖。缺少分數欄位仍顯示 `—`，不擅自代入 0。
2. 原本「個股診斷」遭遇來源未核時直接中斷整頁。現在恢復表單及單股研究（歷史日線／買點分數／報酬／風險／模型參考區）；來源或個股價格日不合格仍不產生可執行 BUY / SELL。
3. 「五日保守預估淨報酬」為負時，報酬／風險比計算值為 **0.00**，本版清楚說明這是「預估沒有正向報酬空間」，不等於資料缺漏。若原始風險／報酬估計缺少必要證據，仍顯示 `—`。
4. 單股診斷優先讀取與模型同日期、至少 260 根交易日的快取。已有模型基準日便不再次呼叫交易所 EOD APIs；詳細技術圖與公司／法人研究需主動開啟，避免未展開的 Streamlit expander 在每次 rerun 仍偷偷載入。
5. 當查詢的個股不在原始完整選股快照時，快速模式可能只有價量歷史、缺少可比公司／法人證據，明確提示 DQ/MC 不可與原榜直接比較。
6. 後端資料來源、個股演算或詳細圖表失敗時，隔離例外，保留診斷入口與已計算資訊，並以 App logs 記錄錯誤類型。

## 已確定保留的風控

- 盤中可執行買點仍須核實的官方成交價、原始成交時間及 180 秒有效時限；不以昨收、委買／委賣或不明欄位補齊即時價。
- 官方兩市日線來源未核、模型日期不一致、或個股日線比模型日期舊，都不得產生 BUY / SELL 訊號。
- 原有 Alpha／DQ／MC、多因子策略權重、風控門檻及 5／40／120 交易日計算沒有重新調參。
- 網路端點若真的無法提供報價，不能透過顯示修正來保證全部價格可取得。

## 線上驗收

1. 頁面應顯示 **V18.17**。在 10/13 這種來源尚未核對但有完整日線模型的情境，「歷史買點分數」應呈現原已計算的值，而不是因未核而全部 `—`。
2. 五日保守淨報酬若為負，會顯示實際負值與風險值；報酬／風險是 0.00 時應有解釋。
3. 進入「個股診斷」，即使日線來源待核，也應出現「診斷目的、股票代碼、週期、分析」表單。選擇「考慮買入／已有持股」後應呈現研究結果；不得標成現在可買／可賣。
4. 若輸入未納入快照的股票，先取快取歷史，對缺少歷史或來源中斷提供具體錯誤；詳細圖表須主動展開再載入。
5. 盤中報價若仍失敗，沿用 V18.16 的「報價來源診斷」下載 JSON；若個股診斷後端失敗，請查看 Streamlit Cloud 的 `Manage app > Logs`，提供 Exception 類型及 traceback 供排查。
